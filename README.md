# 教員業務 Claude Code 自動化リポジトリ

柔道整復師養成専門学校 常勤教員向け。
Claude Code を使って、定型的な文面作成・記録整理・資料作成を省力化する。

---

## 使い方の基本

1. Claude Code を起動（`claude` コマンド）
2. 下のメニューから使いたいものを選ぶ
3. 指示テンプレートに情報を埋めてそのまま貼る
4. 出力を確認して修正・使用する

**最終判断・送信は必ず人間が行う。Claude Code は下書きを作るだけ。**

---

## メニュー一覧

| # | メニュー | フォルダ | 使う場面 |
|---|----------|----------|----------|
| 1 | 定型文ライブラリ | `01_定型文ライブラリ/` | 保護者・学生・提出催促などの文面を最短で作る |
| 2 | 面談記録の整形 | `02_面談記録整形/` | メモを構造化された記録に変換する |
| 3 | 会議資料の毒抜き | `03_会議資料毒抜き/` | お達し・通知から「実際にやること」だけ抽出する |
| 4 | 指導記録の下書き | `04_指導記録/` | 指導の事実を校内提出用の記録文にする |
| 5 | 小テスト・資料作成 | `05_小テスト資料/` | 単元名とレベルを指定して初稿を作る |
| 6 | 評価コメント支援 | `06_評価コメント/` | 成績・観察から通知表・面談コメントを作る |
| 7 | 提出物・名簿整理 | `07_提出物管理/` | CSV・表から未提出一覧・並び替えを処理する |
| 8 | 年度またぎ資産化 | `08_年度資産化/` | 今年の資料を来年使える形で保管する |
| 9 | 判断基準集 | `09_判断基準/` | 文面作成の上限・下限を定義する |

---

## 動作指示

Claude Code がこのリポジトリ内でどう動くかは `CLAUDE.md` に書いてある。
判断基準は `09_判断基準/基準集.md` を参照。

---

## クイックスタート

```
# 面談後すぐに記録を作りたい場合
メモ: [面談メモをそのまま貼る]
→ 02_面談記録整形/template.md の形式で出力

# 会議資料をさばきたい場合
原文: [資料をそのまま貼る]
→ 03_会議資料毒抜き/filter_guide.md の形式で出力

# 保護者に連絡文が必要な場合
状況: 保護者連絡 [A/B/C/D/E]
→ 01_定型文ライブラリ/保護者連絡.md のテンプレートで出力
```
