# 年度またぎ資産化 インデックス

## 目的

今年作った文面・資料・指導メモを来年そのまま使える形で保管する。
「ゼロから作り直す」をなくす。

---

## フォルダ構成（自動作成ルール）

```
08_年度資産化/
├── index.md          ← このファイル
├── 科目別/
│   ├── 解剖学/
│   ├── 生理学/
│   ├── 柔道整復理論/
│   └── （その他科目）
├── 行事別/
│   ├── 入学オリエンテーション/
│   ├── 国家試験対策/
│   ├── 実習/
│   └── 卒業関連/
└── 学年別/
    ├── 1年/
    ├── 2年/
    └── 3年/
```

---

## 使い方

```
種別: [文面 / 資料 / 指導メモ / テンプレート]
分類: [科目別: 解剖学 など / 行事別: 国家試験対策 など / 学年別: 2年 など]
タイトル: [わかりやすい名前]
内容: [保存したい内容をそのまま貼る]
年度: [2025 など]
```

→ 保存先パスと md ファイルの内容を提案する。

## 再利用のコツ

- ファイル名に年度を入れない（内容の中に年度を書く）
  → 来年ファイルを探しやすくするため
- 「今年特有の内容」と「毎年使える内容」を分けて書く
- 固有名詞（学生名・行事の固有日程）は `[〇〇]` プレースホルダーにしておく
