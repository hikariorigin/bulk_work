# 判断基準集

> ここに書いた基準が、このリポジトリで Claude Code が文面を作る際の上限・下限になる。
> 書いていない判断は Claude Code が勝手にしない。随時追記・修正すること。

---

## 1. 学生への言及範囲

### どこまで言う（文面に含める）
- 事実（出席回数・成績・提出状況）
- 教員が取ったアクション
- 次にやること・期限

### どこから言わない（文面に含めない）
- 学生の性格・性質への評価（「だらしない」「やる気がない」等）
- 他の学生との比較
- 家庭環境への言及（本人から聞いた場合でも基本的に書かない）
- 推測・予測（「おそらく〜だと思われる」）

---

## 2. 保護者連絡の判断基準

### 対応フロー（無断欠席）

1. **まず本人へ Teams で連絡**（欠席当日〜翌日）
2. **それでも無断欠席が 3 日以上続く場合 → 保護者連絡**
3. 健康・安全に関わる事案は即保護者連絡
4. 重大な問題行動は主任・学科長に相談してから

### 連絡しない（本人への対応を先行する）
- 単発の遅刻・欠席（理由の申告あり）
- 提出遅れ（学生本人で解決できる範囲）
- 成績の軽微な低下

### 判断が難しい場合
- 主任・学科長に相談してから行動する
- 単独で決定しない

---

## 3. 面談での避ける表現

| 避ける表現 | 理由 | 代替表現 |
|------------|------|----------|
| 「このままでは留年します」 | 断定は権限外 | 「現状では単位取得が難しい状況です」 |
| 「やる気が見えません」 | 主観・評価 | 「出席・提出の状況を確認しています」 |
| 「〜すれば絶対大丈夫」 | 保証は不可 | 「取り組みを続けることが重要です」 |
| 「他の人は〜なのに」 | 比較は不可 | 使わない |
| 「正直言って」 | 曖昧に特別感を出す | 使わない |

---

## 4. 進路指導での最低線

- 国家試験受験資格の取得可否は、教務・学科長の確認なしに断言しない
- 「受かる・受からない」の見込みを文面で伝えない
- 就職先・進路先に関する個人情報は本人の同意なく共有しない
- 受験意思の確認は促すが、強制的な表現は使わない

---

## 5. 校内共有の範囲

### 共有してよい情報
- 出席・成績の数値
- 取ったアクションの事実
- 次回対応の予定

### 共有前に確認が必要な情報
- 本人が相談で話した内容
- 家庭環境・健康状態
- 他の教員から聞いた情報

### 共有しない情報
- 本人が「他の先生に言わないで」と言ったこと（ただし安全上の問題がある場合は除く）
- 個人の見解・評価

---

## 6. Claude Code への制約（このリポジトリ内）

- 懲戒・退学・除籍に関する文面は単独で生成しない
- 法的な助言を含む文面は生成しない
- 生成した文面に「最終確認は必ず人間が行うこと」の注記を常につける
