# 評価コメント支援テンプレート

## 使い方

```
学生メモ: [成績・観察メモを箇条書きで貼る]
用途: [通知表 / 面談 / 内部記録]
学年: [1年 / 2年 / 3年]
```

---

## 出力形式（Claude Code が出力する）

### コメント候補（用途別）

**通知表向け**（50〜80字・事実ベース・肯定的表現）
> 

**面談向け**（話し言葉・具体的・次のアクションを含む）
> 

**内部記録向け**（である調・観察事実・課題点を含む）
>

## コメント作成の原則

| 用途 | 書く内容 | 書かない内容 |
|------|----------|-------------|
| 通知表 | 事実・具体的な行動・成長 | 感情・他学生との比較・否定語 |
| 面談 | 強み＋課題＋次のアクション | 決めつけ・過度な保証 |
| 内部記録 | 観察事実・数値・経緯 | 評価・予測・感情 |

---

## 記録例（入力）

```
学生メモ:
- 出席: ほぼ皆勤
- 定期試験: 平均 72 点（クラス平均 68 点）
- 実技: 手技は丁寧だが動作が遅い
- 授業態度: 集中している・発言は少ない
- 模擬試験: 生理学が弱い（55 点）、解剖学は安定（78 点）
- 提出物: 期限内に全提出
用途: 通知表
学年: 2年
```

## 記録例（出力）

**コメント候補**

**通知表向け**
> 出席状況が良く、提出物を期限内に提出するなど、学習への取り組みは安定している。実技では丁寧な手技が評価できる。引き続き苦手科目の克服に取り組んでほしい。

**努力点**
- 出席率が高く、学習習慣が安定している
- 解剖学の成績がクラス平均を上回っている
- 実技の手技が丁寧

**課題点**
- 生理学の得点が低い（直近模試 55 点）
- 実技の動作速度が遅い（時間内完了に課題あり）
- 授業内の発言・積極的な参加が少ない

---

## 注意

- コメント候補はあくまで草案。最終判断・修正は必ず人間が行う。
- 「できていない」より「〜の向上が期待される」等の表現を使うが、
  事実の歪曲はしない。
- 他の学生と比較する表現は使わない。
