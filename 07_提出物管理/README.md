# 提出物・名簿データ整理

## 使い方

```
データ: [CSV や表をそのまま貼る]
処理: [未提出一覧 / 再提出対象 / 出席並び替え / 印刷用整形]
補足: （任意: 判定基準・フォーマット指定）
```

---

## 対応できる処理

### 未提出一覧
- 提出済み列が空白・「×」・「未」の行を抽出
- 出力: 学籍番号・氏名・未提出課題名

### 再提出対象
- 点数が基準点以下の行を抽出
- 出力: 学籍番号・氏名・得点・基準点

### 出席並び替え
- 学籍番号順・50音順・出席率順 などで並び替え
- 出力: 並び替えた表

### 印刷用整形
- Markdown 表に変換（コピーして Word/Excel に貼り付け可）
- 不要な列を除去
- セルの結合が必要な箇所を「※ここを結合」と注記

---

## データ入力形式の例

### CSV 貼り付け例
```
学籍番号,氏名,第1回,第2回,第3回,合計
2301,山田A,提出,提出,未,
2302,鈴木B,提出,未,未,
2303,田中C,提出,提出,提出,
```

### 処理指示例
```
データ: 上記 CSV
処理: 未提出一覧
補足: 「未」が 1 件以上ある学生を抽出。第3回未提出は特に要注意フラグをつけて
```

---

## 出力例（未提出一覧）

| 学籍番号 | 氏名 | 未提出課題 | 備考 |
|----------|------|------------|------|
| 2301 | 山田 A | 第3回 | ⚠ 第3回未提出 |
| 2302 | 鈴木 B | 第2回・第3回 | ⚠ 第3回未提出 |

---

## 注意事項

- 個人名入りのデータは **このリポジトリにコミットしない**。
  ローカルで処理し、結果だけを使う。
- CSV は直接 Claude Code のプロンプトに貼り付けて処理する。
- 複雑な集計（関数・グラフ）は Excel/Googleスプレッドシートの方が早い場合がある。

## よくある処理パターン

```
# 国家試験模擬試験の合否ライン確認
データ: [模擬試験結果 CSV]
処理: 未提出一覧
補足: 合格基準は 180 点以上（300 点満点）。不合格者を学年・科目別に整理

# 出席簿の整形
データ: [出席簿 CSV]  
処理: 出席並び替え
補足: 出席率（%）を計算して列追加。60% 未満を強調表示

# 提出物の確認
データ: [提出状況一覧]
処理: 未提出一覧
補足: 全課題未提出の学生を最優先でリストアップ
```
