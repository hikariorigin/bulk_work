# 面談記録 整形テンプレート

## 使い方

以下の形式で Claude Code に渡すと、構造化された記録に整形する。

```
メモ: [殴り書き・箇条書きをそのまま貼る]
面談日: [日付]
相手: [学生名（仮名可）/ 保護者同席の有無]
```

---

## 出力形式（Claude Code が出力する）

### 事実
（起きたこと・確認できたことのみ。推測を含まない）

- 
- 

### 気になった点
（教員として注意を向けた観察・発言・態度など）

- 
- 

### 次回対応
（次にとる具体的アクション。期日・担当者も明記）

- [ ] 
- [ ] 

### 校内共有向け表現
（会議・記録簿・引き継ぎに使える無難な表現。固有名詞は最小化）

> 

---

## 記録例（入力）

```
メモ: 
- 遅刻続いてる、本人は「電車が」と言ってたけど毎回それ
- 表情暗い、目合わせない
- 成績は中くらい、実技だけ得意
- バイト？聞いたら否定、でもなんか疲れてそう
- 来月の模試どうするか聞いたら「受けます」とだけ
- 保護者は今のところ連絡不要と本人言ってる
面談日: 3/28
相手: F さん（2 年・単独）
```

## 記録例（出力）

### 事実
- 直近 [期間] で遅刻 [回数] 回。理由として交通機関の遅延を申告。
- 定期試験の成績は中程度。実技評価は高い。
- 次回模擬試験への受験意思を確認済み。
- 本人より保護者への連絡不要との申し出あり。

### 気になった点
- 面談中、視線が合いにくく表情が暗い。
- 疲労感が見受けられる（理由は不明）。
- 遅刻理由について毎回同一の説明。

### 次回対応
- [ ] 遅刻状況を 1 週間後に再確認（担当: 自分）
- [ ] 模擬試験後に成績を確認し、個別フォローの要否を判断
- [ ] 保護者連絡の判断は [期日] までに再検討

### 校内共有向け表現
> 定期面談を実施。出席状況と学習状況を確認した。本人は前向きに取り組む意向を示しており、引き続き経過を見守る。

---

## 注意

- 「校内共有向け表現」は事実の最小限の要約。感情・評価・予測は書かない。
- 「気になった点」は記録として残すが、共有範囲を慎重に判断する。
- 個人名・クラス番号などは共有用ファイルに含めない。
