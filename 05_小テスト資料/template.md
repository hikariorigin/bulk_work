# 小テスト・配布資料 叩き台生成テンプレート

## 使い方

```
科目: [解剖学 / 生理学 / 病理学 / 柔道整復理論 / 関係法規 / 一般臨床医学 など]
単元: [具体的な章・テーマ]
レベル: [基礎 / 標準 / 応用]
学年: [1年 / 2年 / 3年]
種別: [小テスト / ワークシート / 説明プリント / 確認問題]
問題数または分量: （任意）
```

- 一般臨床医学

## 出力形式（種別ごと）

### 小テスト
- 問題数: 指定または 5〜10 問
- 形式: 穴埋め・選択・記述（混合可）
- 解答欄付き
- 解答例を別セクションに出力

### ワークシート
- 図解・表の穴埋め
- 手順の並び替え
- 症例への当てはめ問題

### 説明プリント
- 要点を箇条書き
- 図・表のプレースホルダー（「ここに図 XX を挿入」）
- 学生が書き込める余白を想定したレイアウト指示

### 確認問題
- 授業終わりの 5 分用
- 2〜3 問・即答形式
- 正答率で理解度チェック

## 生成例（入力）

```
科目: 解剖学
単元: 上肢の骨（肩関節周囲）
レベル: 基礎
学年: 1年
種別: 小テスト
問題数: 10問
```

## 生成例（出力イメージ）

**解剖学 小テスト（上肢の骨・肩関節周囲）**  
1 年　　組　　番　氏名：＿＿＿＿＿＿＿＿

---

**【穴埋め】次の（　）に適切な語句を入れなさい。**

1. 肩関節は（　　　）骨と（　　　）骨の間に形成される。
2. 鎖骨は（　　　）端で胸骨と、（　　　）端で肩甲骨と関節する。
3. 肩甲骨の外側角にある関節面を（　　　）という。
4. 上腕骨頭の外側にある隆起を（　　　）、内側を（　　　）という。
5. 腱板を構成する筋は棘上筋・棘下筋・小円筋と（　　　）の 4 つである。

（以下 6〜10 問続く）

---

**【解答例】**（教員控え）

1. 上腕・肩甲 / 2. 胸骨・肩峰 / 3. 関節窩 / 4. 大結節・小結節 / 5. 肩甲下筋

---

## 注意

- 生成物は叩き台。専門用語・問題難易度は必ず人間が確認・修正する。
- 国家試験の出題傾向（過去問ベース）を参考にしたい場合はその旨を追記する。
- 図・画像は含まれない。「図○を参照」の指示を手動で差し替えること。
