# 面談案内 テンプレート集

---

## A. 定期面談（全員対象）

```
[クラス名] の皆さん

[時期] の定期個別面談を下記の通り実施します。

【面談期間】[開始日] 〜 [終了日]
【場所】[場所]
【時間】[1 人あたりの時間] 程度
【内容】学習状況・生活・進路について

日程調整表を [配布方法] で配布しますので、[期限] までに記入してください。

[担当教員名]
```

---

## B. 個別呼び出し面談

```
[学生名] さん

個別に話したいことがあります。

【日時】[日時]
【場所】[場所]
【所要時間】[時間] 程度

都合が悪い場合は事前に相談してください。

[担当教員名]
```

---

## C. 保護者同席面談の案内

```
[保護者名] 様

[学生名] さんの学習・進路について、保護者様を交えてお話しする機会を設けたいと思います。

【候補日時】
- [候補1]
- [候補2]
- [候補3]

【場所】[場所]
【所要時間】[時間] 程度

ご都合のよい日時をお知らせください。

[学校名] [学科名]
[担任・担当教員名]  TEL: [連絡先]
```

---

## D. 国家試験対策面談

```
[学生名] さん

国家試験に向けた学習状況を確認するため、面談を行います。

【日時】[日時]
【場所】[場所]
【持参物】直近の模擬試験結果・自己学習記録

準備して来てください。

[担当教員名]
```

---

## Claude Code への指示例

```
状況: 面談案内 C（保護者同席）
学生名: D さん（3 年）
理由: 国家試験の合否ライン前後で推移しており、方針確認が必要
候補日: 来週火曜・木曜・再来週月曜 いずれも 16 時以降
```
