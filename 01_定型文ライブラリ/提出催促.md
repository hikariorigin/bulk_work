# 提出催促 テンプレート集

---

## A. 初回催促（穏やか）

```
[学生名] さん

[科目名]「[課題名]」の提出期限（[日付]）が過ぎています。
[対応期限] までに提出してください。

[担当教員名]
```

---

## B. 二度目の催促（明確）

```
[学生名] さん

[課題名] についてはすでに一度連絡しましたが、まだ提出がありません。
[最終期限] までに必ず提出してください。

それ以降は受け付けられず、評価に影響します。

[担当教員名]
```

---

## C. 最終通告（記録残し用）

```
[学生名] さん

[課題名] の提出について、これが最終の確認です。
[最終期限] を過ぎた場合、[対応: 欠点扱い / 再履修 / 補講] となります。

この連絡は記録として保管します。

[担当教員名]  [日付]
```

---

## D. クラス一斉通知

```
[クラス名] の皆さん

[科目名]「[課題名]」の提出期限は [日付] です。
未提出の方は必ず提出してください。

提出方法: [方法]
提出先: [提出先]

[担当教員名]
```

---

## Claude Code への指示例

```
状況: 提出催促 B（二度目）
課題名: 解剖学 第3章レポート
学生名: C さん
最終期限: 今週金曜
評価への影響: 評価点から 20% 減点
```
