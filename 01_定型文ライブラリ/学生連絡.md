# 学生連絡 テンプレート集

---

## A. 面談呼び出し

```
[学生名] さん

[日時] に [場所] で話したいことがあります。
時間は [所要時間] 程度を予定しています。
都合が悪い場合は事前に連絡してください。

[担当教員名]
```

---

## B. 提出物・課題の未提出確認

```
[学生名] さん

[科目名] の [課題名・提出物名] がまだ届いていません。
期限は [日付] でした。

[対応期限] までに [提出方法] で提出してください。
それ以降は受け付けられない場合があります。

[担当教員名]
```

---

## C. 実技・出席の状況確認

```
[学生名] さん

[科目名] の出席状況を確認したところ、現時点で [回数] 回の欠席があります。
単位取得には [基準] 以上の出席が必要です。

今後の出席について、一度話し合いたいと思います。
[日時] に [場所] へ来てください。

[担当教員名]
```

---

## D. 国家試験・進路の確認促し

```
[学生名] さん

国家試験の受験手続き・進路希望について確認したいことがあります。
[期限] までに [書類名 / 確認事項] を [提出先 / 連絡方法] で対応してください。

不明な点は遠慮なく聞きに来てください。

[担当教員名]
```

---

## E. 体調不良・早退後のフォロー

```
[学生名] さん

[日付] は体調不良で帰宅しましたが、その後はいかがですか。
回復次第、[担当者] まで状況を教えてください。
無理せず、体調優先で対応してください。

[担当教員名]
```

---

## Claude Code への指示例

```
状況: 学生連絡 C（出席不足）
学生名: B さん（2 年）
欠席回数: 6 回（基準: 3 回まで）
呼び出し日時: 来週月曜 放課後
```
