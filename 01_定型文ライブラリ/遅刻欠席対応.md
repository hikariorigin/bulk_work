# 遅刻・欠席対応 テンプレート集

---

## A. 欠席連絡の受け取り確認（学生宛）

```
[学生名] さん

欠席の連絡を受け取りました。
[日付] の [科目・時限] は欠席扱いとして処理します。

体調不良の場合は無理をせず、回復したら状況を教えてください。

[担当教員名]
```

---

## B. 無断欠席への確認連絡

```
[学生名] さん

[日付]、連絡なく欠席していました。
体調や状況に問題がないか確認したいので、[期限] までに連絡してください。

連絡がない場合は、保護者へ確認する場合があります。

[担当教員名]
```

---

## C. 遅刻が続く場合の注意

```
[学生名] さん

直近 [期間] で [回数] 回の遅刻がありました。
遅刻が続く場合、出席扱いの基準に影響することがあります。

一度話し合いたいと思います。[日時] に [場所] へ来てください。

[担当教員名]
```

---

## D. 長期欠席への対応通知

```
[学生名] さん（保護者様）

[学生名] さんが [日付] から [日数] 日間欠席しています。
学習の遅れや出席状況について確認が必要です。

お早めにご連絡いただけますでしょうか。

[学校名] [学科名]
[担任・担当教員名]  TEL: [連絡先]
```

---

## E. 公欠・忌引き処理の確認

```
[学生名] さん

[日付] の欠席について、[公欠 / 忌引き] として処理する場合は、
[必要書類] を [期限] までに [提出先] へ提出してください。

提出がない場合は通常の欠席扱いとなります。

[担当教員名]
```

---

## Claude Code への指示例

```
状況: 遅刻欠席対応 B（無断欠席）
学生名: E さん（1 年）
欠席日: 今週月曜・火曜（連続・連絡なし）
次のアクション: 本日中に連絡なければ保護者連絡
```
