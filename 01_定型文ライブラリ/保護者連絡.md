# 保護者連絡 テンプレート集

> 使い方: 状況に近いテンプレートを選び、[ ] 内を埋めて Claude Code に渡す。

---

## A. 欠席・遅刻の連絡受け取り確認

```
[保護者名] 様

本日は [学生名] さんの欠席（遅刻）についてご連絡いただき、ありがとうございます。
[日付] の [科目・時限] については欠席（遅刻）として処理いたします。
引き続きよろしくお願いいたします。

[学校名] [学科名]
[担任・担当教員名]
```

---

## B. 学生の状況共有（要注意）

```
[保護者名] 様

[学生名] さんの学校生活について、一度ご連絡させていただきたいことがございます。
お時間をいただけますでしょうか。

ご都合のよい日時を教えていただけますと幸いです。

[学校名] [学科名]
[担任・担当教員名]  TEL: [連絡先]
```

---

## C. 面談日程の調整

```
[保護者名] 様

[学生名] さんの [定期面談 / 個別面談] について日程をご調整いたします。
以下の候補日からご選択いただけますでしょうか。

- [候補1: 日時・所要時間]
- [候補2: 日時・所要時間]
- [候補3: 日時・所要時間]

ご都合が合わない場合はご遠慮なくお知らせください。

[学校名] [学科名]
[担任・担当教員名]  TEL: [連絡先]
```

---

## D. 国家試験・進路に関する連絡

```
[保護者名] 様

[学生名] さんの進路・国家試験対策について、
現状と今後の方針をお伝えしたく連絡いたしました。

[要点を 2〜3 行で記載]

ご不明な点がございましたら、いつでもご連絡ください。

[学校名] [学科名]
[担任・担当教員名]  TEL: [連絡先]
```

---

## E. 緊急連絡（体調不良・事故等）

```
[保護者名] 様

[学生名] さんが本日 [時刻] 頃、[状況を一文で]。
現在 [対応中の状況]。
お手数ですが、[連絡先] までご連絡いただけますでしょうか。

[学校名] [学科名]
[担任・担当教員名]  TEL: [連絡先]
```

---

## Claude Code への指示例

```
状況: 保護者連絡 B（要注意）
学生名: A さん（3 年）
内容: 実技の出席が不足しており、このままでは単位取得が難しい状況
トーン: 事実ベース、穏やか
```
