# 面談報告書 テンプレート

> 使い方: [ ] 内を埋めて印刷・提出。Claude Code に「面談報告書を作って」と内容を渡せば内容欄の下書きを出力する。

---

## 出力イメージ（印刷用）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
　　　　　　　面　談　報　告　書
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

                              [年月日]
                    報告者: [氏名1]　[氏名2]

1. 報告事項: [学科名・学年] 学生面談について

2. 対 象 者: [学科名・学年] [クラス]
             学籍番号: [番号]　氏名: [氏名]

3. 面 談 者: [担当教員名]

4. 日　　時: [年月日（曜日）] [開始時刻]〜[終了時刻]

5. 場　　所: [校舎・教室名]

6. 内　　容:

[本文]

                                        以上

┌──────┬──────┬──────┐
│　校長　│教務部長│　学科長│
│　　　　│　　　　│　　　　│
│　　　　│　　　　│　　　　│
└──────┴──────┴──────┘
```

---

## Claude Code への指示例

```
誰に: [学生名（仮名可）・学年・クラス]
面談者: [教員名]
日時: [日時]
内容メモ: [殴り書きをそのまま]
用途: 面談報告書（校内提出・承認欄あり）
```

→ 「6. 内容」欄の本文を校内提出用の表現で出力する。

---

## 内容欄 文体ルール

- である調
- 事実ベース・感情表現なし
- 学生の行動・発言は「〜した」「〜と述べた」
- 評価語（「だらしない」「やる気がない」等）は使わない
- 保護者の状況は「保護者との連絡済み」等の事実のみ
- 承認欄が必要な書類のため、表現は特に無難化する

---

## 保存場所

`04_指導記録/提出済み/[年度]/面談報告書_[日付]_[仮名].md`

※ 提出済みの記録は個人名を除いた形で保管する。

---

※ 要確認箇所:
- 承認欄の順序（校長・教務部長・学科長）は校内書式に合わせて変更
- 報告者欄の氏名順は慣例に従うこと
