# 指導記録 下書き生成テンプレート

## 使い方

```
誰に: [学生名（仮名可）・学年]
いつ: [日時]
何を: [指導・対応の内容を箇条書き]
どう対応した: [とったアクション]
次のアクション: （任意）
```

---

## 出力形式（Claude Code が出力する）

**校内提出用記録文**（である調・事実ベース・感情表現なし）

> 

**記録メモ（内部保管用）**

- 対応者: 
- 対応日時: 
- 相手: 
- 内容の要点: 
- 次回対応: 

---

## 指導記録の種類と文体の目安

| 種類 | 文体 | 共有範囲 |
|------|------|----------|
| 校内提出用（会議・引き継ぎ） | である調・簡潔・事実のみ | 担当者以外も読む |
| 担任内部メモ | 自由・観察含む | 担任のみ |
| 生活指導記録 | である調・時系列 | 生活指導担当 |
| 進路指導記録 | である調・具体的 | 進路担当 |

---

## 記録例（入力）

```
誰に: G さん（3 年）
いつ: 3/28 昼休み
何を:
- 模擬試験の成績が直近 2 回連続で合格ラインを下回っている
- 自習の様子を見ていると集中できていない時間が多い
- 本人に声がけしたところ、「やっている」と返答
どう対応した:
- 苦手科目（生理学・病理学）を具体的に確認
- 来週までに自分で学習計画を作って持ってくるよう伝えた
次のアクション: 来週月曜に学習計画の提出を確認
```

## 記録例（出力）

**校内提出用記録文**

> 3 月 28 日昼休み、3 年 G に対して個別指導を実施した。直近 2 回の模擬試験において合格基準に達していないため、学習状況の確認を行った。本人に苦手科目（生理学・病理学）を確認し、来週中に自身で学習計画を作成・提出するよう指示した。

**記録メモ（内部保管用）**

- 対応者: [担当教員名]
- 対応日時: 3/28（月）昼休み
- 相手: 3 年 G
- 内容の要点: 模試不振・苦手科目確認・学習計画作成を指示
- 次回対応: 来週月曜 学習計画提出確認

---

## 注意事項

- 校内提出用には個人の感情・推測・評価を書かない（「やる気がない」等は不可）
- 「指示した」「確認した」「伝えた」の動詞を使う
- 「〜と思われる」は使わない
- 本人の発言を引用する場合は「〜と述べた」「〜と申告した」
